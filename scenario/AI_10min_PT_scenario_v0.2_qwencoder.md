## 제작 참고사항

### Remotion 장면 목록
1. 채팅 입력창 애니메이션 (도입)
2. 터미널 `req.txt` 반복 실행 → 429 오류 (전개 1)
3. 실제 프로그램 화면 슬라이드쇼 (전개 2)
4. 깨진 출력물·에러 화면 (위기)
5. 역할 분담 다이어그램 (절정)
6. 시나리오 작성 타임라인 (결말)

### Google Flow 장면 목록
1. 집에서 스마트폰 질문하는 일상 (도입)
2. 반복 타이핑으로 피곤한 표정 (전개 1)
3. 프로그램 성공 후 미소 (전개 2)
4. 괴상한 3D 캐릭터에 당황 → 웃음 (위기)
5. 3 개 모니터로 역할 분담하는 모습 (절정)
6. 카메라 보며 자신감 있는 미소 (결말)

### 실제 화면 에셋
- ChatGPT 대화 기록 (개인정보 모자이크)
- GitHub 저장소 `Exit8_67`, `hanja_quiz` 캡처
- history 폴더 markdown 표지
- CSV Diff 분석기, QR 리더, 관용어 퀴즈 웹앱 실행 화면

### TTS 음성 설정
- 40 대 남성 계열, 친근하고 차분한 톤
- 유머 장면 (429 오류, 배치파일 깨짐) 에서 짧은 호흡과 타이밍 조절
- 결말 메시지는 약간 느리게, 강조하여 낭독
