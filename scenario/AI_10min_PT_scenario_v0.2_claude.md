## 0. 이 시나리오의 설계

### 0.1 한 문장 기획

ERP를 운영하는 40대 회사원 한 명이 **산에서 찍은 버섯 사진 한 장**으로 AI를 처음 써본 뒤, 아이 숙제와 잔일에 계속 쓰다 보니 프로그램·게임·영상·자동화까지 넓어진 석 달을 시간 순서로 보여준다. 그래서 보는 사람이 "저 정도 시작이면 나도 오늘 해보겠다"고 느끼게 한다.

### 0.3 감정 곡선

머쓱함 → 사소한 재미 → 반복의 피로 → 웃긴 실패 → 만드는 재미 → 요령이 생김 → 담담한 여유 → 조용한 초대

### 0.4 숨은 구조 (제작진용 · 영상에 용어 노출 금지)

요구사항 §7의 개념은 **장면의 뼈대로만** 쓰고, 화면 자막·내레이션·아이콘 어디에도 용어를 쓰지 않는다.

| 개념 | 대응 챕터 | 화면에서 보이는 것 |
|---|---|---|
| Prompt | 1~3장 | 한 줄 질문, 사진 한 장 |
| Context | 6장 | 파일에 적어 둔 지시문, 한 줄 실행 |
| Skill | 9장 | 이름 붙여 저장한 반복 작업 |
| Harness·검증 | 8장 | 인수인계 문서, 검토 보고서, 정리해 둔 지식 |
| Loop | 4·5·7장 | 실패 → 수정 → 다시 실행의 반복 컷 |
| Graph | 10장 | 정리 문서가 다른 쪽으로 넘어가는 장면 |

### 0.5 절대 하지 않는 것

- "안 쓰면 뒤처진다" 류의 공포 메시지
- "여러분도 해보세요" 류의 직접 지시·훈계 문장
- 도구 로고 나열 화면, 도구 이름 3개 연속 호명
- 아이 얼굴·가족 사진·학습 진단 결과 원본 노출
- 사내 SAP 화면, 고객사 데이터, 실제 사번·조직명 노출

### 0.6 시각 원칙 (요구사항 §11 반영)

- 흰 배경 + 굵은 검정 제목 + **빨강·주황 강조 1색만**
- 화면 상단을 가로지르는 얇은 강조선이 챕터 전환의 유일한 장치
- 한 화면에 메시지 하나. 표·박스 최소화
- 날짜는 화면 우상단에 작은 회색 캡션(`06 / 29`)으로만 표기해 시간 흐름을 감각적으로 전달
